## What pkgdiff answers

- **What changed?** Pick a "from" and a "to" version and read every release note in between as one
  timeline, sorted into breaking changes, features, fixes, deprecations and security fixes.
- **Is the upgrade safe?** Known vulnerabilities of every version from OSV, what the upgrade fixes and
  what it introduces, malware warnings and project health (OpenSSF Scorecard, licenses, provenance).
- **What about my whole project?** Paste a `package.json`, `.csproj`, `requirements.txt`,
  `pubspec.yaml` or a lock file at [pkgdiff.dev/audit](https://pkgdiff.dev/audit) and get a shareable
  report of every dependency's vulnerabilities and the version that fixes them.
